    사용 환경

    위플랩 커스텀 CSS에서 사용 가능합니다. 치지직, SOOP 모두 제작해요.

    수정 범위

    CSS 전달 전까지 디자인 수정 2회 가능합니다.

    CSS 전달 후에는 오류에 대한 대응만 해드리고 있어요. 파일을 전달받으신 이후 디자인 변경, 수정 등은 어렵습니다.

    일정 · 마감

    문의순이 아닌 입금순으로 진행됩니다.

    입금한 날짜로부터 15일 마감이에요. 짧은 기간에 신청이 몰리면 입금 순서대로 진행하며 마감기한이 변동될 수 있어요. 빠른 마감은 추가금이 있어요.

    오류 대응 · 오픈카톡방

    일정 기간(약 2주)이 지난 후 오류에 대한 제보가 없다고 판단되면 의뢰를 진행하신 오픈카톡방은 삭제합니다.
