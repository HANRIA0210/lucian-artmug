🔑 비밀번호 설정

GitHub 접근 키는 이번 한 번만 넣으면 돼요. 키는 비밀번호로 잠가서 저장하고, 다음부터는 비밀번호만 입력하면 들어가져요.

← 비밀번호로 들어가기

키 만드는 법
  1. GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → lucian-artmug
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate 후 나온 키를 복사해서 위 칸에 붙여 넣기
